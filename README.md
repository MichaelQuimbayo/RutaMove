# RutaMove
Conectar pasajeros y conductores para viajes intermunicipales de forma organizada, en tiempo real y sin depender de WhatsApp.

Ejecutar el build runner
```
FVM dart run build_runner watch
```

ANDROID APK:
```bash
cd  P:\RutaMove | P:\RutaMove\.fvm\flutter_sdk\bin\flutter.bat build apk --flavor dev --release
```
